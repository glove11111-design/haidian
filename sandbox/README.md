# 数字沙盘 · 建筑单体

面向设计师的网页沙盘：Three.js 加载一栋建筑，可看层、点选房间、剖切、测距、日照和标注。无后端，浏览器内渲染。

未放置 GLB 时，会自动生成一座可读的四层演示体量（`Floor_01`…`Floor_04`，若干命名房间），所有交互可直接试用。

## 本地运行

在本目录执行：

```bash
cd sandbox
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 [http://localhost:5173](http://localhost:5173)）。

打包为静态站点：

```bash
npm run build
npm run preview
```

`dist/` 可放到 Pages / OSS 等静态托管。不要把 `node_modules/` 提交进仓库。

## 替换建筑模型

1. 在 Blender 中按米制整理建筑（楼层命名、房间作为子级、应用缩放）。更完整的导出约定见 [blender-export.md](./blender-export.md)。
2. 导出 **glTF 2.0 Binary（`.glb`）**。
3. 将文件放到：

```text
sandbox/public/models/building.glb
```

重新运行 `npm run dev`（或刷新已开着的开发服务），沙盘会优先加载该文件。

也可以在页面里：

- 点左侧 **导入**，选择 `.glb`
- 把 `.glb` 拖进窗口

导入只作用于当前浏览器会话，不会写入磁盘。要让所有访客默认看到你的楼，请把文件放到上面的 `public/models/building.glb` 再构建。

单位按米处理。若模型整体尺寸明显像毫米（最大边超过 250），加载时会自动按 0.001 缩放到米，并在画面上提示。

## 交互

| 操作 | 说明 |
| --- | --- |
| 旋转 / 平移 / 缩放 | 左键拖拽、右键或中键平移、滚轮缩放 |
| 重置 | 左侧「重置」，或按 `R` |
| 楼层 | 底部「全部」或某一层；数字键 `1`–`9` 隔离对应层，`0` 显示全部 |
| 点选 | 点击房间或楼板，右侧显示名称、楼层、面积估算和占位属性 |
| 剖切 | 打开剖切后拖动高度；可选水平或竖直裁剪面 |
| 测距 | 切换到测距，在模型上点两点，读出米制距离 |
| 日照 | 顶栏时间滑杆，改变太阳方向与天光 |
| 标注 | 点击表面放下图钉，可在侧栏改写说明 |

## 命名约定（与 Blender 对齐）

- 楼层物体或集合导出后名称：`Floor_01`、`Floor_02`…
- 房间作为对应楼层的子物体，使用可读中文或英文名（如 `一层门厅`、`会议室A`）
- 不要把整栋楼 Merge / Join 成一块网格，否则无法按层、按房间点选
- 原点放在地面中心附近；+Z 向上（Blender 导出 glTF 时会转到 Y-up）
